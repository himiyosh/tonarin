はじめて起動するときThe first launch

アプリにはまだ Apple の公証も Windows のコード署名もないため、最初の一度だけ確認が出ます。 The app is not notarized by Apple or code signed for Windows yet, so each system asks once before the first start.

macOS Apple Silicon

  1. .dmg を開き、Tonarin を「アプリケーション」フォルダへドラッグします。
  2. Tonarin を開くと、はじめは確認のできないアプリとして止められます。「システム設定」→「プライバシーとセキュリティ」の下のほうにある「このまま開く」をクリックして、もう一度開きます (macOS 14 以前は、Tonarin を右クリック →「開く」)。
  3. マイクへのアクセスを許可します。設定の「接続」が開くので、Gemini の API キーを貼り付けるとペットが目を覚まします。
  1. Open the .dmg and drag Tonarin to the Applications folder.
  2. Open Tonarin. macOS stops it the first time: go to System Settings → Privacy & Security, click Open Anyway near the bottom and open it again (on macOS 14 and earlier: right-click Tonarin → Open).
  3. Allow microphone access. Settings opens at Connection: paste your Gemini API key and the pet wakes up.

Windows 10 / 11 プレビューPreview

  1. Tonarin-…-setup.exe を実行します。あなたのアカウントにだけインストールされ、管理者の権限は要りません。
  2. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を選びます。
  3. インストールが終わると Tonarin が起動し、通知領域 (タスクバーの右端) にアイコンが出ます。設定の「接続」で Gemini の API キーを貼り付けてください。
  1. Run Tonarin-…-setup.exe. It installs for your account only and needs no admin rights.
  2. If Windows says “Windows protected your PC”, choose More info → Run anyway.
  3. Tonarin starts when the installer finishes, with its icon in the notification area (the right end of the taskbar). Paste your Gemini API key in Settings → Connection.

マイクが使えないときは、Windows の「設定」→「プライバシーとセキュリティ」→「マイク」で「デスクトップ アプリがマイクにアクセスできるようにする」をオンにします。 If the microphone does not work, turn on “Let desktop apps access your microphone” in Windows Settings → Privacy & security → Microphone.

用意するものWhat you need

Gemini の API キー (無料)A Gemini API key (free)
Google AI Studio で発行できます。無料枠では、送った内容が Google の製品改善に使われ、人が読む場合があります。個人的な話は避けるか、有料枠を使ってください。 Get one from Google AI Studio. On the free tier Google may use what you send to improve its products, and people may read it: keep personal matters out, or use the paid tier.
GitHub Copilot (なくても使えます)GitHub Copilot (optional)
深掘りの質問に使います。プランは問いません。Copilot CLI で一度サインインしておいてください。なくても会話はできます。 Used for deep dives, on any plan. Sign in once with the Copilot CLI. Without it Tonarin still talks, just without deep dives.
マイクA microphone
声らしい音がしたときだけ Gemini に送ります。おやすみ中とミュート中はマイクを閉じます。話した内容はログに残しません。 Only voice-like sound is sent to Gemini. The mic is closed while the pet naps or is muted, and nothing you say is logged.
