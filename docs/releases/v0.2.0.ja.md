## v0.2.0 のハイライト

v0.2.0 は Apple Silicon の Mac 向けに初めてダウンロードできる版で、Windows 10 / 11 向けはプレビュー版です。Tonarin はデスクトップに住む小さなキャラクターです。Gemini Live でリアルタイムに話し、じっくり考える質問は GitHub Copilot に任せます。

### 新しくなったこと

#### ニュース

- 「設定」→「ニュース」で総合・経済・科学・暮らしや自分で追加した取得元をオン・オフでき、公開 HTTPS のサイト URL または HTTPS の RSS/Atom フィード URL を追加できます。サイト URL からのフィード自動検出、組込候補・追加サイト別の監視件数、追加サイトの上限 10 件に対する使用数・残数も表示します。従来の日英テクノロジー系 12 件は既定のまま、新しい組込候補はすべて初期オフです。
- キーワード通知は、ニュースでオンにした取得元だけを確認します。すべてオフならフィードにアクセスせず、自動実行の履歴に理由をエラーとして残し、通知します。確認に成功したとは表示しません。
- 日本語の任意候補には、PDL1.0 に基づき出典を示して本文を利用できるデジタル庁・総務省のお知らせと、大阪府の新着情報・しごと／産業・くらし／環境のお知らせを追加しました。大阪府と従来のテック系は RSS の見出し・概要・原記事リンクだけを使い、同じホストを追加サイトに登録し直しても本文を取得しません。英語の GOV.UK・NSF は、許可された行政・科学ニュースの本文を出典付きで読めます。
- 大手報道機関について、Tonarin の AI 要約に利用できると規約まで確認できた RSS はありませんでした。そのため組込候補には追加していません。日本語の科学に該当する組込候補がないときは「候補なし」（英語表示では「No sources available」）と示します。英語の科学ニュース候補は利用できます。
- 自分で追加したサイトの記事本文は、登録した正確なホストで robots.txt と転送先を確認してからだけ取得します。Cookie やログイン情報を送らず、有料記事の制限も回避しません。有料・会員限定の表示を検知したら、本文を返さず原記事リンクと理由だけを案内します。未知のソフトペイウォールは匿名 GET の前に必ず判定できるわけではありません。

#### 使用量と料金

- 「設定」→「使用量と料金」の「有料枠の料金ガイド」を「会話とマイク」「自動実行と停止」「調査と情報取得」の 3 グループに整理し、装飾用のアイコンを加えました。説明を読むための画面で、請求や設定は変更しません。

#### メール模擬（任意のデモ）

- Mac と Windows で Gmail 型・Outlook 型の認可コードと PKCE/state 確認、模擬トークンを架空のデータだけで試せる、初期オフのオフライン MOCK/DEMO です。Google / Microsoft のアプリ登録や実アカウントでのサインイン、実際のメール接続先・権限・受信箱へのアクセスはありません。
- 架空の差出人・件名を通知し、端末に入っている声で読み上げられます。架空の本文を見るには別の同意が必要で、さらにメッセージごとの AI 転送の同意も模擬だけです。実メールの取得や AI への送信・要約は行わず、新しい OS 権限も求めません。

#### Windows (プレビュー)

- Windows 10 / 11 で動くようになりました (x64 と ARM64)。インストーラーはあなたのアカウントにだけ入れるので、管理者の権限は要りません。終わるとそのまま起動します。
- ペットは Mac と同じようにデスクトップにいます。いつも手前に表示され、吹き出しは空いている側に開き、画面をロックするとおやすみします。通知領域にはカラーのアイコンが出て、左クリックでもペットの右クリックと同じメニューが開きます。
- Gemini の API キー、アプリ連携のトークン、GitHub のサインインは、Windows のデータ保護 (DPAPI) で暗号化して保存します。読めるのはあなたの Windows アカウントだけです。
- 起動中にもう一度 Tonarin を開くと、2 つ目は起動せず、いまのペットを表示します (表示中なら設定を開きます)。
- 設定画面は Windows のタイトルバーとフォントを使い、「この PC」「Windows の設定」「Ctrl」など Windows の言葉で説明します。「Mac のカレンダー」のプリセットは macOS でだけ表示します。

#### ダウンロードとリリース

- リリースの公開ファイルには、Apple Silicon の Mac 用ディスクイメージと zip、Windows x64 / ARM64 用インストーラーがあり、`SHA256SUMS.txt` で SHA-256 のチェックサムを確認できます。
- Mac 版はアドホック署名で Apple の公証は受けていません。Windows 版はコード署名がありません。初回起動時に macOS の Gatekeeper または Windows の SmartScreen に警告される場合があります。
- [ダウンロードページ](https://himiyosh.github.io/tonarin/) では、お使いのパソコンに合ったファイルを選び、はじめての起動方法と日英のリリースノートを読めます。

#### キャラクター

- ダウンロードした Codex / ChatGPT のペット (zip) を追加するのに、unzip コマンドが要らなくなりました。zip からpet.json とスプライトシートだけをメモリ上で読み、サイズとチェックサムを確かめます。

### 不具合の修正と改善

- 設定画面やペットの吹き出し、メニュー、通知の日本語を自然な表現に整えました。macOS の権限案内と Windows 固有の操作案内も見直しています。
- 起動時の Copilot サインイン確認が応答しない場合、独立した SDK の実行状態確認に応答があるときだけ、時間制限付きで 1 回再試行します。デスクトップ側もその最大待機時間に合わせて状態を確認します。有効なサインイン状態の応答は引き続き必要で、Windows の実行環境や SDK が応答しない状態が続けば起動に失敗する場合があります。
- Windows で Tonarin を終了すると、起動していた Copilot のランタイムとアプリ連携のサーバーも止まるようになりました。Windows にはシグナルがないため、ローカルのプロキシにメッセージで停止を頼み、止まるのを待ちます。
- アプリ連携のコマンドは Windows の検索パスをそのまま使い、`~\` がホームフォルダーになります。
- Windows で設定ウィンドウを開いたとき、フォーカスがペットに移ってしまうことがなくなりました。

### 開発する方へ

- `npm run dist` は、実行した OS 向けにビルドします。Mac では `Tonarin-<version>-mac-arm64.dmg` と `.zip`、Windows では `Tonarin-<version>-win-<arch>-setup.exe` です (`-- --arch x64|arm64`)。
- `npm run smoke` は、パッケージしたアプリを一時的な設定フォルダーで起動し、両方の画面、プロキシ、Copilot のランタイム、ウィンドウの配置、トレイアイコンを確かめて、きれいに終了できることを確認します。
- `npm run pet:bundled` が Windows でも動くようになり、`TONARIN_USER_DATA` で別の設定フォルダーを使えます。

### コントリビューターの方へ

- CI は Windows でもユニットテストを実行し、アプリに変更があるたびに macOS と Windows のアプリをビルドして起動テストします。
- `main` に `vX.Y.Z` のタグを付けると、ビルド、確認、`docs/releases/` のノートでのリリース公開、ダウンロードページの更新まで自動で行います。
