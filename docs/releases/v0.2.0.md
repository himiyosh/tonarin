## v0.2.0 Highlights

The first release you can download and install: Tonarin now comes as an app for Apple Silicon Macs, and as a preview for Windows 10 and 11. New here? Tonarin is a small character that lives on your desktop, talks with you in real time through Gemini Live, and hands the careful thinking to GitHub Copilot.

### Product updates

#### Windows (preview)

- Tonarin runs on Windows 10 and 11, on x64 and ARM64 PCs. The installer sets it up for your account only, with no admin rights, and starts it right away.
- The pet sits on your desktop just like on a Mac: always on top, the speech bubble opening on whichever side has room, naps when you lock the screen, and a colored icon in the notification area. A left click on that icon opens the same menu as the pet's right click.
- Your Gemini API key, connected-app tokens and the GitHub sign-in are encrypted with Windows data protection (DPAPI), so only your Windows account can read them.
- Starting Tonarin again while it runs brings back the pet (or opens Settings) instead of a second copy.
- Settings uses the Windows title bar and fonts, and speaks of "this PC", Windows Settings and Ctrl instead of Mac terms. The Mac Calendar preset is only offered on macOS.

#### Downloads and releases

- Every release now comes with a disk image and a zip for Apple Silicon Macs and installers for Windows, with SHA-256 checksums.
- [The download page](https://himiyosh.github.io/tonarin/) picks the right file for your computer, walks you through the first launch and keeps the notes for every release, in English and Japanese.

#### Characters

- Adding a Codex / ChatGPT pet from a downloaded zip no longer needs an unzip tool: Tonarin reads only pet.json and the spritesheet out of the archive, in memory, and checks their sizes and checksums.

### Bug fixes and polish

- Quitting Tonarin on Windows also stops the Copilot runtime and the connected-app servers it started. Windows has no signals, so the app now asks its local proxy to stop with a message and waits for it.
- Connected-app commands keep Windows' own search path, and `~\` works as your home folder there.
- The settings window no longer loses focus to the pet when it opens on Windows.

### To developers

- `npm run dist` builds for the platform it runs on: `Tonarin-<version>-mac-arm64.dmg` and `.zip` on a Mac, `Tonarin-<version>-win-<arch>-setup.exe` on Windows (`-- --arch x64|arm64`).
- `npm run smoke` starts a packaged build with a temporary settings folder, checks both pages, the proxy, the Copilot runtime, the window layout and the tray icon, and confirms that everything shuts down gracefully.
- `npm run pet:bundled` works on Windows too, and `TONARIN_USER_DATA` runs the app with another settings folder.

### To contributors

- CI runs the unit tests on Windows as well, and builds and smoke-tests the macOS and Windows apps whenever the app changes.
- A `vX.Y.Z` tag on `main` builds, checks and publishes the release with these notes from `docs/releases/`, then refreshes the download page.
