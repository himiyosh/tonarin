## v0.2.0 Highlights

v0.2.0 is Tonarin's first downloadable release for Apple Silicon Macs, with a preview for Windows 10 and 11. New here? Tonarin is a small character that lives on your desktop, talks with you in real time through Gemini Live, and hands the careful thinking to GitHub Copilot.

### Product updates

#### News

- Settings → News lets you switch general, business, science, living and personal sources on or off, and add HTTPS site URLs (with automatic feed discovery) or direct HTTPS RSS/Atom feed URLs. It shows watched built-in and personal-source counts and used/remaining slots out of the 10-site limit for added sites. The original 12 Japanese and English technology feeds remain the defaults; every new built-in source is off by default.
- Keyword watches check only the News sources you have enabled. With all sources off, they make no feed requests and record a clear error in automation history and a notification instead of reporting a successful check.
- Japanese opt-in sources include Digital Agency and MIC updates, whose government-authored text can be reused with attribution under PDL1.0, plus Osaka Prefecture's general, work/industry and living/environment notices. The Osaka feeds and the original technology feeds provide only RSS headlines, descriptions and original links; they never fetch article bodies, even if you add the same host as a personal site. English GOV.UK and NSF sources can provide permitted government-authored article text with source credit.
- No large-media RSS source was verified as eligible for Tonarin's AI summaries, so none is bundled. Japanese science has no eligible built-in source and displays 「候補なし」 (or “No sources available” in the English interface); English science sources are still available.
- For a personal site with a readable feed, Tonarin reads an article only on the exact host you added, after checking its robots.txt rules and any same-host redirects. It sends no cookies or sign-in credentials and never bypasses a subscription. If a paywall or members-only page is detected, it returns the original link and a reason instead of article text; an unknown soft paywall cannot always be identified before an anonymous GET.

#### Usage & cost

- In Settings → Usage & cost, the paid-tier billing guide groups its explanations under conversation/microphone, automations/stopping and research/data, with decorative icons. It is read-only: it does not change billing or settings.

#### Mail mock (opt-in demo)

- A default-off, offline MOCK/DEMO on Mac and Windows simulates fictional Gmail- and Outlook-style authorization-code flows with PKCE/state checks and fake tokens. It requires no Google or Microsoft app registration, provider account or sign-in, live mail endpoint, production mail scope or real mailbox access.
- Fictional sender/subject notifications can be read aloud with installed local voices. Viewing a fictional message body needs its own opt-in; a further per-message consent only simulates AI transfer, sending nothing and producing no summary. The demo never fetches real mail or requests new OS permissions.

#### Windows (preview)

- Tonarin runs on Windows 10 and 11, on x64 and ARM64 PCs. The installer sets it up for your account only, with no admin rights, and starts it right away.
- The pet sits on your desktop just like on a Mac: always on top, the speech bubble opening on whichever side has room, naps when you lock the screen, and a colored icon in the notification area. A left click on that icon opens the same menu as the pet's right click.
- Your Gemini API key, connected-app tokens and the GitHub sign-in are encrypted with Windows data protection (DPAPI), so only your Windows account can read them.
- Starting Tonarin again while it runs brings back the pet (or opens Settings) instead of a second copy.
- Settings uses the Windows title bar and fonts, and speaks of "this PC", Windows Settings and Ctrl instead of Mac terms. The Mac Calendar preset is only offered on macOS.

#### Downloads and releases

- Release assets include a disk image and zip for Apple Silicon Macs and x64/ARM64 Windows installers, with SHA-256 checksums in `SHA256SUMS.txt`.
- The Mac app is ad hoc signed and not notarized by Apple; the Windows installers are unsigned. macOS Gatekeeper or Windows SmartScreen may show a warning on first launch.
- [The download page](https://himiyosh.github.io/tonarin/) selects the right file for your computer, explains the first launch and shows release notes in English and Japanese.

#### Characters

- Adding a Codex / ChatGPT pet from a downloaded zip no longer needs an unzip tool: Tonarin reads only pet.json and the spritesheet out of the archive, in memory, and checks their sizes and checksums.

### Bug fixes and polish

- Japanese wording is more natural in Settings, the pet's speech bubble, menus and notifications, including macOS permission prompts and Windows-specific guidance.
- If the Copilot sign-in check stalls during startup, it can retry once within a bounded interval, but only after an independent SDK runtime status check responds. The desktop now waits through that bounded interval; a valid sign-in status is still required, and ongoing Windows runner or SDK stalls can still cause startup failure.
- Quitting Tonarin on Windows also stops the Copilot runtime and the connected-app servers it started. Windows has no signals, so the app now asks its local proxy to stop with a message and waits for it.
- Connected-app commands keep Windows' own search path, and `~\` works as your home folder there.
- The settings window no longer loses focus to the pet when it opens on Windows.

### To developers

- `npm run dist` builds for the platform it runs on: `Tonarin-<version>-mac-arm64.dmg` and `.zip` on a Mac, `Tonarin-<version>-win-<arch>-setup.exe` on Windows (`-- --arch x64|arm64`).
- `npm run smoke` starts a packaged build with a temporary settings folder, checks both pages, the proxy, the Copilot runtime, the window layout and the tray icon, and confirms that everything shuts down gracefully.
- `npm run pet:bundled` works on Windows too, and `TONARIN_USER_DATA` runs the app with another settings folder.

### To contributors

- CI runs the unit tests on Windows as well, and builds and smoke-tests the macOS and Windows apps whenever the app changes.
- A `vX.Y.Z` tag on `main` builds, checks and publishes the release with these notes from `docs/releases/`, then refreshes the download page.
